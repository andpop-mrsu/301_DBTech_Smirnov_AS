# Описание данных

В папке Task01 находятся следующие файлы:

- ratings.csv — оценки пользователей (userId, movieId, rating, timestamp)
- movies.csv — информация о фильмах (movieId, title, genres)
- tags.csv — теги пользователей к фильмам (userId, movieId, tag, timestamp)
- users.txt — данные пользователей (userId, name, email, gender, birthdate, occupation)
- occupation.txt — список профессий (id, occupation)
- genres.txt — список жанров (id, genre)
- ratings_count.txt — мин. и макс. userId с количеством оценок
- sqlite.txt — версия SQLite и режимы вывода
